# Before going live

Fill these in `config/salon.json`. Until then the site shows them as "to confirm".

- [ ] `address`: studio address (and `mapsUrl`, a Google Maps link to it)
- [ ] `phoneDisplay`: phone number, if Klaudia wants one on the site (or delete the line)
- [ ] `email`: optional
- [ ] `hours`: opening hours for each day, written how they should read, e.g. `"10am to 6pm"` or `"Closed"`
- [ ] `bookingUrl`: a booking page (Fresha, Booksy, etc.) if she has one; leave empty to keep booking by Instagram message
- [ ] `bookingNote`: check the wording of how to book
- [ ] `tagline` and each service's `description`: check they say what she'd say
- [ ] A domain, and `PUBLIC_URL` set to it on the host
